# Vanilla JS Word Counter & Analytics App

A lightweight, responsive single-page Word Counter web application built using modern vanilla JavaScript (ES6+), semantic HTML5, and modern CSS3 (Flexbox/Grid and CSS variables).

## Features
- **Real-time Metrics**: Tracks total word count, total character count, characters excluding spaces, and total sentence count dynamically on user input.
- **Estimated Reading Time**: Calculated at a standard reading pace of 200 WPM (displays seconds for shorter texts, minutes for longer texts).
- **Top 5 Most Used Words**: Identifies the top 5 most frequent words while ignoring specified stop-words (`the`, `a`, `and`) and automatically stripping surrounding punctuation.
- **Dark Mode Card Layout**: Clean, accessible, responsive design with responsive CSS Grid/Flexbox layouts.
- **Zero Dependencies**: Pure web standards solution with no build tools or frameworks required.
